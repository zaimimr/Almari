# Care Label Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let her photograph a piece's care label, read it on the phone, and store fibres, size, brand and origin with the piece, setting its fabric attribute with source `label` without ever overwriting a confirmed value.

**Architecture:** Swift in `modules/closet-vision` reads the label photo with Apple Vision (`readLabel`) and runs a care label model on the text with a fixed schema (`extractLabel`). The model is Cactus Needle 3 fine-tuned on this Mac with LoRA on synthetic care label text (Tasks 6 and 7), and it ships only if it measurably helps. Pure TypeScript in `src/domain/careLabel.ts` turns that output into a `CareLabel`: a deterministic text reader and the model are merged, the one chosen by measurement goes first and the other only fills empty fields, every value must be printed on the label, and model output below the measured confidence threshold (when the model reports one) is dropped. Screens call the domain through `src/state/careLabel.ts` and `useCloset().update`, so the domain and its tests never need the engine.

**Tech Stack:** Expo SDK 57, React Native 0.86, expo-router, TypeScript, `tsx --test`, Swift with Vision, Cactus Needle 3 (engine `libneedle.a` and base `needle3.cact` from Hugging Face `Cactus-Compute/needle3` at revision `27c0a9a5b3ca835e0b7dbeaccf555df03dac493d`), Python 3.12 with `uv` and `cactus-needle` 3.0.6 for the recorded evaluation, `cactus-needle[train,metal]` (JAX 0.4.38 with `jax-metal` 0.1.1, flax 0.10.4, optax 0.2.5) for local LoRA fine-tuning on Apple Silicon, Maestro 2.11.

**Spec:** [planning/implementation/LABELS-CAPTURE-STYLING.md](../implementation/LABELS-CAPTURE-STYLING.md), section "Part 3: Care label". Shared contracts: [2026-10-01-00-overview.md](2026-10-01-00-overview.md).

## Research findings this plan is built on

Measured on 1 October 2026 on this Mac (Xcode 27.0, "Closet Development" simulator on iOS 27.0). Task 1 repeats the checks and records them.

- Engine files: Hugging Face `Cactus-Compute/needle3` holds `ios-arm64/libneedle.a` (1,137,864 bytes), `ios-sim-arm64/libneedle.a` (1,155,504 bytes), `needle.h` (1,187 bytes, identical in both folders) and `needle3.cact` (35,335,380 bytes). `needle download ios-arm64 --out <dir>` from `pip install cactus-needle` fetches the same files; this plan uses `curl` against the pinned revision so the bytes and checksums never change underneath it. Both libraries are single-slice arm64 static libraries built with `minos 27.0`, so they go into an xcframework rather than `vendored_libraries`.
- C API (`needle.h`): `needle_load(const unsigned char* cact, unsigned long long n)` loads the weights from memory (the engine copies them; freeing the buffer right after load worked), `needle_init(system_prompt, tools_json, tool_index_path)` declares the schema as the only tool, `needle_reset()` clears the conversation, `needle_complete(input, max_new_tokens, out, out_capacity)` writes one JSON envelope, `needle_last_error()` explains a negative return. One process-global model, not thread safe, so all calls go through one serial queue.
- The envelope: `{"type":"call","function_calls":[...],"suppressed_calls":[...],"confidence":0.0113,"reasoning":"...","peak_ram_mb":80.2,...}`. Calls below the engine floor of 0.1 move from `function_calls` to `suppressed_calls`; the record is `arguments` of the first call in either list. `confidence` is the calibrated score in [0, 1].
- Telemetry: the README says the binary has telemetry on by default and is turned off with `NEEDLE_TELEMETRY=0` and `DO_NOT_TRACK=1`. The iOS static library imports no network or environment symbols at all (`nm -u` shows no `socket`, `connect`, `getaddrinfo`, `getenv`, CFNetwork or NSURLSession), so it cannot send anything; the app still sets both variables with `setenv` before `needle_load`, as the overview requires, and the final TestFlight build gets a network check on her iPhone.
- On the simulator the iOS engine loads and initialises in 158 ms, extracts one label in 330 to 440 ms and peaks at 80 MB. Linking it into the app's iOS 26.0 deployment target gives one linker warning ("built for newer 'iOS-simulator' version (27.0) than being linked (26.0)") and runs correctly.
- Vision `VNRecognizeTextRequest` (accurate, language correction) runs in the simulator and supports `en-US, fr-FR, de-DE, tr-TR, nb-NO, no-NO` among others. Urdu is not supported, so Urdu-script lines are read poorly or not at all; Urdu-English labels are handled through their English and numeric parts.
- Needle 3 base quality on the 15 fixture labels with the schema in Task 1 (cactus-needle 3.0.6, engine 3.0.2, Mac): with no threshold it gets 12 of 45 expected fields right and 12 wrong; at 0.05 it gets 2 right and 0 wrong; at 0.1 and above it returns nothing, because every label scored below the engine floor. The deterministic text reader in Task 2 gets 40 of 45 (everything except brand) with 0 wrong. Reader plus Needle at 0.05 also gets 40 of 45 with 0 wrong. Brands stay empty, which the spec allows ("fields stay empty and editable"). The reader's rules were written together with these fixtures, so its score is optimistic.
- Owner decision, 1 October 2026: fine-tune Needle for care labels rather than drop it, and keep the app's minimum at iOS 26, because her iPhone runs iOS 26.

Fine-tuning, checked on this Mac (Apple M2 Pro, 32 GB, macOS 27) against the Needle repository at commit `ea68f2eb955f110e15c8706a85a87c1bbf63698b`, its `llms.txt` and README, and the guide at https://cactuscompute.com/blog/finetuning-needle:

- Local route, no account: `needle finetune data.jsonl --out adapter.safetensors` trains LoRA adapters on the attention projections of the frozen 20-layer base (default rank 16, alpha 32, learning rate 1e-4, batch 16, 10% of the file held back for validation loss), downloading the base checkpoint from Hugging Face on first use. `needle build --lora adapter.safetensors --layers N --out tuned.cact` merges the adapter, slices the first N layers (any rung from 2 to 20) and exports 4-bit weights. The engine is weights-agnostic, so the same `libneedle.a` runs a tuned `.cact`.
- Data: JSONL, one example per line, either `query`/`tools`/`answers` or chat format (`messages` with one user turn and one assistant turn whose `tool_calls` carry `arguments` as a JSON string, plus OpenAI-form `tools`). Both formats train the same way locally, and chat format also works on the hosted platform. An example with no call has an empty `tool_calls` list; the guide suggests roughly one such example in eight. Thousands of examples are recommended for argument grounding; rank 32 for grounding-heavy tasks.
- `needle generate-data` and `needle finetune --generate` call an OpenRouter model and need `OPENROUTER_API_KEY`, so this plan does not use them. Training data comes from a seeded local script instead (Task 6).
- A locally tuned model has no confidence head: `needle build --lora` leaves it out, and the engine reports `confidence` as `null`. So the confidence threshold only applies to models that report one (the base model, or a platform-tuned model). For a local LoRA model the threshold becomes `null`, and the printed-on-label checks in `parseExtraction` are the only gate. `parseExtraction` and `readLabelText` take `threshold: number | null` for this reason.
- `pip install "cactus-needle[train,metal]"` resolves on Python 3.12 to cactus-needle 3.0.6, jax and jaxlib 0.4.38, jax-metal 0.1.1, flax 0.10.4 and optax 0.2.5. On this Mac, JAX reported `[METAL(id=0)]` and ran a matrix product on the GPU. The guide measures 0.71 s per training step with Metal against 2.90 s on CPU on an M5 Max; the M2 Pro is slower, and Task 7 records the real time.
- Hosted alternative: `needle platform finetune` trains the full model at every depth on Cactus GPUs, mixes in Needle's original data, trains and calibrates the confidence head and exports 2-bit weights. It needs a `NEEDLE_API_KEY` that only the owner can create, and it uploads the training files. Task 7 describes it as an alternative only.

iOS 26, checked on this Mac:

- `otool -l` on both prebuilt engine libraries shows `minos 27.0`, `sdk 27.0`. The spike binary linked from it for `arm64-apple-ios26.0-simulator` shows `minos 26.0`, `sdk 27.0` in `vtool -show-build`, so the app's own deployment target decides the minimum OS, not the library.
- The device library imports 122 symbols: plain C library functions (`malloc_zone_pressure_relief`, `mmap`, `sysctlbyname`, `pthread_create` and similar) and long-standing libc++ functions (strings, regex, `condition_variable`, `steady_clock`). None looked like an iOS 27 addition, but that is not proof.
- The engine has only run in the iOS 27.0 simulator. This Mac has simulator runtimes for iOS 17.5, 18.5 and 27.0 and none for iOS 26, so Task 1 installs one and runs the engine on it. Task 1's result picks the path for Task 8: no gate if it runs, otherwise an `#available(iOS 27, *)` gate around the extractor.

## Review Focus

1. A label in a script Vision cannot read (Urdu), or a photo with no label text: every field stays empty and editable and nothing is guessed. Pinned by fixtures `mixed-urdu-silk` and `en-unreadable` in tests C01, C05 and C06 (Task 2).
2. A multilingual label that repeats one fibre in four languages, or lists shell and lining separately: one entry per fibre and no invented percentages. Pinned by fixtures `mixed-nordic` and `en-shell-lining` in C01 and C05, and by C03 for percentages that are not printed (Task 2).
3. A piece whose fabric she already confirmed, then a label that says something else: the confirmed fabric stays, the label is still stored. Pinned by C13 (Task 4).
4. Editing the piece name or photo after adding a label: the label and its fabric survive the editor's save. Pinned by the rename steps in `.maestro/care-label/piece.yaml` (Task 9) and by C16 for saving and reopening (Task 4).
5. Removing the label: only a fabric that came from the label is cleared, other attributes stay. Pinned by C15 (Task 4) and the remove steps in `piece.yaml` (Task 9).
6. The tuned model is judged on labels it never saw: no fixture or real label text, and no fixture brand, appears in the training data. Pinned by the leak check in `care_label_data.py` (Task 6) and by recording held-out results separately from the synthetic validation used to pick the depth (Task 7).
7. The tuned model ships only when it earns its place: as the primary reader only if it beats the text rules on held-out labels with no more wrong fields, otherwise only to fill fields the rules left empty, otherwise not at all. A model with no confidence score can still never add a value that is not printed on the label. Pinned by C02 and C07 (Task 2) and C19 (Task 7).
8. Her iPhone on iOS 26: the app still installs and launches with a 26.0 deployment target, and label reading works there either through the engine or, if the engine cannot run on iOS 26, through the text reader alone. Pinned by the iOS 26 simulator run in Task 1 Step 6 and the iOS 26 flow in Task 9 Step 9.

- [ ] **Step 4: Run the engine inside the simulator with a small C program**

Create `$SPIKE/spike.c`:

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#include "needle.h"

static char *slurp(const char *path, long *size) {
  FILE *file = fopen(path, "rb");
  if (!file) return NULL;
  fseek(file, 0, SEEK_END);
  *size = ftell(file);
  fseek(file, 0, SEEK_SET);
  char *data = malloc(*size + 1);
  fread(data, 1, *size, file);
  data[*size] = 0;
  fclose(file);
  return data;
}

static long now_ms(void) {
  struct timespec t;
  clock_gettime(CLOCK_MONOTONIC, &t);
  return t.tv_sec * 1000 + t.tv_nsec / 1000000;
}

int main(int argc, char **argv) {
  setenv("NEEDLE_TELEMETRY", "0", 1);
  setenv("DO_NOT_TRACK", "1", 1);
  long weights_size = 0, schema_size = 0;
  char *weights = slurp(argv[1], &weights_size);
  char *schema = slurp(argv[2], &schema_size);
  if (!weights || !schema) return 2;
  long started = now_ms();
  if (needle_load((const unsigned char *)weights, (unsigned long long)weights_size) < 0) {
    fprintf(stderr, "load failed: %s\n", needle_last_error());
    return 3;
  }
  free(weights);
  int prefix = needle_init("", schema, NULL);
  if (prefix < 0) {
    fprintf(stderr, "init failed: %s\n", needle_last_error());
    return 4;
  }
  printf("load+init ms=%ld prefix=%d\n", now_ms() - started, prefix);
  static char out[65536];
  for (int i = 3; i < argc; i++) {
    long begin = now_ms();
    needle_reset();
    int rc = needle_complete(argv[i], 512, out, (int)sizeof out);
    printf("rc=%d ms=%ld\n%s\n", rc, now_ms() - begin, out);
  }
  return 0;
}
```

export type LabelMaterial = { fibre: string; percent: number | null };

export type LabelFields = {
  materials: LabelMaterial[];
  size?: string;
  brand?: string;
  origin?: string;
};

export type CareLabel = LabelFields & { photo: string };

export type Extraction = { json: string | null; confidence: number | null };

export type LabelDraft = {
  materials: { fibre: string; percent: string }[];
  size: string;
  brand: string;
  origin: string;
};

export const labelConfidenceThreshold: number | null = 0.05;

export const labelPrimary: "rules" | "model" = "rules";

const limits = { fibre: 40, size: 20, brand: 40, origin: 40 };

const fibreWords: Record<string, string[]> = {
  cotton: [
    "cotton",
    "bomull",
    "bomuld",
    "baumwolle",
    "coton",
    "algodon",
    "cotone",
    "pamuk",
  ],
  polyester: ["polyester", "poliester", "poliestere", "polyesteri"],
  viscose: ["viscose", "viskose", "viskos", "viscosa", "viskon", "rayon"],
  elastane: [
    "elastane",
    "elastan",
    "elasthan",
    "elasthanne",
    "elastano",
    "elastam",
    "spandex",
  ],
  wool: ["wool", "ull", "uld", "wolle", "laine", "lana", "yun"],
  silk: ["silk", "silke", "siden", "seide", "soie", "seda", "seta", "ipek"],
  linen: ["linen", "lin", "hør", "leinen", "lino", "keten"],
  modal: ["modal"],
  acrylic: [
    "acrylic",
    "akryl",
    "polyacryl",
    "acrylique",
    "acrilico",
    "akrilik",
  ],
  nylon: [
    "nylon",
    "polyamide",
    "polyamid",
    "poliamid",
    "poliamida",
    "poliammide",
    "naylon",
  ],
};

const fibreByWord = new Map(
  Object.entries(fibreWords).flatMap(([fibre, words]) =>
    words.map((word) => [word, fibre] as const),
  ),
);

function clean(value: string) {
  return value
    .normalize("NFD")
    .replace(/\p{M}/gu, "")
    .toLowerCase()
    .replace(/\s+/g, " ")
    .trim();
}

function escape(value: string) {
  return value.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");
}

function printed(value: string, text: string) {
  const wanted = clean(value);
  if (!wanted) return false;
  return new RegExp(
    `(^|[^\\p{L}\\p{N}])${escape(wanted)}(?=$|[^\\p{L}\\p{N}])`,
    "u",
  ).test(clean(text));
}

function printedPercent(percent: number, text: string) {
  return new RegExp(`(^|[^\\p{N}])${percent}\\s*%`, "u").test(text);
}

function isRecord(value: unknown): value is Record<string, unknown> {
  return typeof value === "object" && value !== null && !Array.isArray(value);
}

function isText(value: unknown, max: number): value is string {
  return (
    typeof value === "string" &&
    value.trim().length > 0 &&
    value.trim().length <= max
  );
}

function isPercent(value: unknown): value is number {
  return (
    typeof value === "number" &&
    Number.isInteger(value) &&
    value >= 0 &&
    value <= 100
  );
}

export function fibreName(value: string): string | null {
  for (const word of clean(value).split(/[^\p{L}]+/u)) {
    const fibre = fibreByWord.get(word);
    if (fibre) return fibre;
  }
  return null;
}

function unique(materials: LabelMaterial[]) {
  return materials.filter(
    (material, index) =>
      materials.findIndex((item) => item.fibre === material.fibre) === index,
  );
}

function withText(
  fields: LabelFields,
  key: "size" | "brand" | "origin",
  value: unknown,
  text: string,
): LabelFields {
  return isText(value, limits[key]) && printed(value, text)
    ? { ...fields, [key]: value.trim() }
    : fields;
}

export function parseExtraction(
  text: string,
  extraction: Extraction,
  threshold: number | null = labelConfidenceThreshold,
): LabelFields {
  const empty: LabelFields = { materials: [] };
  if (
    extraction.json === null ||
    (threshold !== null &&
      (extraction.confidence === null || extraction.confidence < threshold))
  )
    return empty;
  let value: unknown;
  try {
    value = JSON.parse(extraction.json);
  } catch {
    return empty;
  }
  if (!isRecord(value)) return empty;
  const materials = unique(
    (Array.isArray(value.materials) ? value.materials : []).flatMap(
      (item): LabelMaterial[] => {
        if (!isRecord(item) || !isText(item.fibre, limits.fibre)) return [];
        const fibre = fibreName(item.fibre);
        if (!fibre || !printed(item.fibre, text)) return [];
        const percent =
          isPercent(item.percent) && printedPercent(item.percent, text)
            ? item.percent
            : null;
        return [{ fibre, percent }];
      },
    ),
  );
  let fields: LabelFields = { materials };
  fields = withText(fields, "size", value.size, text);
  fields = withText(fields, "brand", value.brand, text);
  fields = withText(fields, "origin", value.origin, text);
  return fields;
}

export function hasLabelFields(fields: LabelFields) {
  return Boolean(
    fields.materials.length || fields.size || fields.brand || fields.origin,
  );
}

export function isCareLabel(value: unknown): value is CareLabel {
  return (
    isRecord(value) &&
    isText(value.photo, 200) &&
    Array.isArray(value.materials) &&
    value.materials.every(
      (item) =>
        isRecord(item) &&
        isText(item.fibre, limits.fibre) &&
        (item.percent === null || isPercent(item.percent)),
    ) &&
    (value.size === undefined || isText(value.size, limits.size)) &&
    (value.brand === undefined || isText(value.brand, limits.brand)) &&
    (value.origin === undefined || isText(value.origin, limits.origin))
  );
}

export function draftFromLabel(fields?: LabelFields): LabelDraft {
  return {
    materials: (fields?.materials ?? []).map((material) => ({
      fibre: material.fibre,
      percent: material.percent === null ? "" : String(material.percent),
    })),
    size: fields?.size ?? "",
    brand: fields?.brand ?? "",
    origin: fields?.origin ?? "",
  };
}

export function labelFromDraft(photo: string, draft: LabelDraft): CareLabel {
  const materials = unique(
    draft.materials.flatMap((item): LabelMaterial[] => {
      const typed = item.fibre.trim().slice(0, limits.fibre);
      if (!typed) return [];
      const digits = item.percent.trim().replace(/\s*%$/, "");
      const percent = /^\d{1,3}$/.test(digits) ? Number(digits) : null;
      return [
        {
          fibre: fibreName(typed) ?? typed.toLowerCase(),
          percent: percent !== null && percent <= 100 ? percent : null,
        },
      ];
    }),
  );
  const label: CareLabel = { photo, materials };
  for (const key of ["size", "brand", "origin"] as const) {
    const value = draft[key].trim().slice(0, limits[key]);
    if (value) label[key] = value;
  }
  return label;
}

export function labelSummary(fields: LabelFields): string[] {
  return [
    fields.materials
      .map((material) =>
        material.percent === null
          ? material.fibre
          : `${material.percent}% ${material.fibre}`,
      )
      .join(", "),
    fields.size ? `Size ${fields.size}` : "",
    fields.brand ? `Brand ${fields.brand}` : "",
    fields.origin ? `Made in ${fields.origin}` : "",
  ].filter(Boolean);
}

const fibreFirst = /(\p{L}+)\s*(\d{1,3})\s*%/gu;
const percentFirst = /(\d{1,3})\s*%\s*(\p{L}+)/gu;
const sizeAfterWord =
  /\b(?:size|str|størrelse|eur)\b\.?\s*:?\s*(XXXL|XXL|XXS|XL|XS|S|M|L|\d{2})\b/i;
const sizeAlone = /^(XXXL|XXL|XXS|XL|XS|S|M|L)$/i;
const madeIn = /\b(?:made in|produsert i|tillverkad i)\s+(\p{L}[\p{L} ]*)/iu;

function materialsIn(line: string) {
  const pairs = (pattern: RegExp, fibreAt: 1 | 2) =>
    [...line.matchAll(pattern)].flatMap((match) => {
      const fibre = match[fibreAt]!;
      return fibreName(fibre)
        ? [{ fibre, percent: Number(match[fibreAt === 1 ? 2 : 1]) }]
        : [];
    });
  const first = /^\s*\p{L}/u.test(line) ? pairs(fibreFirst, 1) : [];
  return first.length ? first : pairs(percentFirst, 2);
}

export function extractFromText(text: string): Extraction {
  const lines = text.split("\n");
  const materials = lines.flatMap(materialsIn);
  const size =
    text.match(sizeAfterWord)?.[1] ??
    lines.map((line) => line.trim()).find((line) => sizeAlone.test(line));
  const origin = text.match(madeIn)?.[1]?.trim();
  const found = {
    ...(materials.length ? { materials } : {}),
    ...(size ? { size } : {}),
    ...(origin ? { origin } : {}),
  };
  return Object.keys(found).length
    ? { json: JSON.stringify(found), confidence: 1 }
    : { json: null, confidence: null };
}

function mergeFields(first: LabelFields, second: LabelFields): LabelFields {
  const merged: LabelFields = {
    materials: first.materials.length ? first.materials : second.materials,
  };
  for (const key of ["size", "brand", "origin"] as const) {
    const value = first[key] ?? second[key];
    if (value) merged[key] = value;
  }
  return merged;
}

export function readLabelText(
  text: string,
  extraction: Extraction,
  threshold: number | null = labelConfidenceThreshold,
  primary: "rules" | "model" = labelPrimary,
): LabelFields {
  const rules = parseExtraction(text, extractFromText(text), null);
  const model = parseExtraction(text, extraction, threshold);
  return primary === "model"
    ? mergeFields(model, rules)
    : mergeFields(rules, model);
}

import fixtures from "./fixtures/care-labels.json";
import recorded from "./fixtures/care-labels.needle.json";
import {
  parseExtraction,
  readLabelText,
  type Extraction,
  type LabelFields,
} from "./careLabel";

export type CareLabelFixture = {
  id: string;
  language: "en" | "nb" | "mixed";
  text: string;
  ideal: Record<string, unknown> | null;
  expected: LabelFields;
};

export type Score = {
  expected: number;
  correct: number;
  wrong: number;
  missed: number;
};

export type Reader = "model" | "rules" | "rules-first" | "model-first";

export const careLabelFixtures = fixtures as unknown as CareLabelFixture[];

export const recordedExtractions = recorded.extractions as unknown as Record<
  string,
  Extraction
>;

const none: Extraction = { json: null, confidence: null };

const same = (a?: string, b?: string) => a?.toLowerCase() === b?.toLowerCase();

function fieldsFor(
  text: string,
  extraction: Extraction,
  threshold: number | null,
  reader: Reader,
): LabelFields {
  if (reader === "model") return parseExtraction(text, extraction, threshold);
  if (reader === "rules") return readLabelText(text, none, threshold, "rules");
  return readLabelText(
    text,
    extraction,
    threshold,
    reader === "model-first" ? "model" : "rules",
  );
}

export function scoreExtractions(
  labels: CareLabelFixture[],
  extractions: Record<string, Extraction>,
  threshold: number | null,
  reader: Reader,
): Score {
  const score: Score = {
    expected: 0,
    correct: 0,
    wrong: 0,
    missed: 0,
  };
  for (const fixture of labels) {
    const got = fieldsFor(
      fixture.text,
      extractions[fixture.id] ?? none,
      threshold,
      reader,
    );
    const want = fixture.expected;
    const key = (item: LabelFields["materials"][number]) =>
      `${item.fibre}:${item.percent}`;
    const wanted = want.materials.map(key);
    const found = got.materials.map(key);
    score.expected += wanted.length;
    score.correct += found.filter((item) => wanted.includes(item)).length;
    score.missed += wanted.filter((item) => !found.includes(item)).length;
    score.wrong += found.filter((item) => !wanted.includes(item)).length;
    for (const field of ["size", "brand", "origin"] as const) {
      if (want[field]) score.expected += 1;
      if (want[field] && same(got[field], want[field])) score.correct += 1;
      else if (got[field]) score.wrong += 1;
      if (want[field] && !same(got[field], want[field])) score.missed += 1;
    }
  }
  return score;
}

export function scoreRecorded(
  threshold: number | null,
  withTextReader: boolean,
): Score {
  return scoreExtractions(
    careLabelFixtures,
    recordedExtractions,
    threshold,
    withTextReader ? "rules-first" : "model",
  );
}

export function fabricFromMaterials(materials: LabelMaterial[]): Fabric | null {
  const main = [...materials].sort(
    (a, b) => (b.percent ?? -1) - (a.percent ?? -1),
  )[0];
  return main ? (fibreFabric[main.fibre] ?? null) : null;
}

function dropFabric<T extends { fabric?: unknown }>(value: T | undefined) {
  if (!value) return undefined;
  const copy = { ...value };
  delete copy.fabric;
  return Object.keys(copy).length ? copy : undefined;
}

export function withCareLabel(
  piece: Piece,
  label: CareLabel | undefined,
): Piece {
  const next: Piece = { ...piece };
  if (label) next.label = label;
  else delete next.label;
  const source = piece.sources?.fabric;
  const confirmed =
    piece.attributes?.fabric !== undefined &&
    (source === undefined || source === "confirmed");
  if (confirmed) return next;
  const fabric = label ? fabricFromMaterials(label.materials) : null;
  if (fabric) {
    next.attributes = { ...piece.attributes, fabric };
    next.sources = { ...piece.sources, fabric: "label" };
    return next;
  }
  if (source !== "label") return next;
  const attributes = dropFabric(piece.attributes);
  const sources = dropFabric(piece.sources);
  if (attributes) next.attributes = attributes;
  else delete next.attributes;
  if (sources) next.sources = sources;
  else delete next.sources;
  return next;
}

```swift
import ExpoModulesCore
import Foundation
import ImageIO
import Vision

struct ReadLabelResult: Record {
  @Field var photo: String = ""
  @Field var lines: [String] = []
}

enum CareLabelError: Error, CustomStringConvertible {
  case unreadable
  case storage

  var description: String {
    switch self {
    case .unreadable: return "unreadable"
    case .storage: return "storage"
    }
  }
}

final class CareLabelReader {
  static let shared = CareLabelReader()

  private let queue = DispatchQueue(label: "closet.vision.label")
  private let languages = ["en", "nb", "de", "fr", "tr", "ur"]

  private var photos: URL {
    FileManager.default.urls(for: .documentDirectory, in: .userDomainMask)[0]
      .appendingPathComponent("closet-photos", isDirectory: true)
  }

  func read(sourceUri: String, id: String) throws -> ReadLabelResult {
    try queue.sync { try run(sourceUri: sourceUri, id: id) }
  }

  private func run(sourceUri: String, id: String) throws -> ReadLabelResult {
    let source = sourceUri.hasPrefix("file://") ? URL(string: sourceUri)! : URL(fileURLWithPath: sourceUri)
    try FileManager.default.createDirectory(at: photos, withIntermediateDirectories: true)
    let ext = source.pathExtension.isEmpty ? "jpg" : source.pathExtension.lowercased()
    let name = "\(id)-label.\(ext)"
    let target = photos.appendingPathComponent(name)
    if !FileManager.default.fileExists(atPath: target.path) {
      do { try FileManager.default.copyItem(at: source, to: target) } catch { throw CareLabelError.storage }
    }
    do {
      var result = ReadLabelResult()
      result.photo = name
      result.lines = try recognize(target)
      return result
    } catch {
      try? FileManager.default.removeItem(at: target)
      throw CareLabelError.unreadable
    }
  }

  private func recognize(_ url: URL) throws -> [String] {
    guard let source = CGImageSourceCreateWithURL(url as CFURL, nil),
      let image = CGImageSourceCreateImageAtIndex(source, 0, nil)
    else { throw CareLabelError.unreadable }
    let properties = CGImageSourceCopyPropertiesAtIndex(source, 0, nil) as? [CFString: Any]
    let orientation =
      (properties?[kCGImagePropertyOrientation] as? UInt32).flatMap(CGImagePropertyOrientation.init(rawValue:)) ?? .up
    let request = VNRecognizeTextRequest()
    request.recognitionLevel = .accurate
    request.usesLanguageCorrection = true
    let supported = (try? request.supportedRecognitionLanguages()) ?? []
    request.recognitionLanguages = languages.compactMap { code in
      supported.first { $0 == code || $0.hasPrefix("\(code)-") }
    }
    try VNImageRequestHandler(cgImage: image, orientation: orientation).perform([request])
    return (request.results ?? []).compactMap {
      $0.topCandidates(1).first?.string.trimmingCharacters(in: .whitespaces)
    }
    .filter { !$0.isEmpty }
  }
}
```

    let target = photos.appendingPathComponent(name)
    if !FileManager.default.fileExists(atPath: target.path) {
      do { try FileManager.default.copyItem(at: source, to: target) } catch { throw CareLabelError.storage }
    }
    do {
      var result = ReadLabelResult()
      result.photo = name
      result.lines = try recognize(target)
      return result
    } catch {
      try? FileManager.default.removeItem(at: target)
      throw CareLabelError.unreadable
    }
  }

  private func recognize(_ url: URL) throws -> [String] {
    guard let source = CGImageSourceCreateWithURL(url as CFURL, nil),
      let image = CGImageSourceCreateImageAtIndex(source, 0, nil)
    else { throw CareLabelError.unreadable }
    let properties = CGImageSourceCopyPropertiesAtIndex(source, 0, nil) as? [CFString: Any]
    let orientation =
      (properties?[kCGImagePropertyOrientation] as? UInt32).flatMap(CGImagePropertyOrientation.init(rawValue:)) ?? .up
    let request = VNRecognizeTextRequest()
    request.recognitionLevel = .accurate
    request.usesLanguageCorrection = true
    let supported = (try? request.supportedRecognitionLanguages()) ?? []
    request.recognitionLanguages = languages.compactMap { code in
      supported.first { $0 == code || $0.hasPrefix("\(code)-") }
    }
    try VNImageRequestHandler(cgImage: image, orientation: orientation).perform([request])
    return (request.results ?? []).compactMap {
      $0.topCandidates(1).first?.string.trimmingCharacters(in: .whitespaces)
    }
    .filter { !$0.isEmpty }
  }
}

final class LabelExtractor {
  static let shared = LabelExtractor()

  private let queue = DispatchQueue(label: "closet.vision.extract")
  private var started = false
  private var output = [CChar](repeating: 0, count: 65536)

  private var bundle: Bundle? {
    let host = Bundle(for: LabelExtractor.self)
    guard let url = host.url(forResource: "ClosetVisionResources", withExtension: "bundle") else { return nil }
    return Bundle(url: url)
  }

  func extract(text: String) throws -> LabelExtraction {
    try queue.sync { try run(text: text.trimmingCharacters(in: .whitespacesAndNewlines)) }
  }

  private func start() throws {
    if started { return }
    setenv("NEEDLE_TELEMETRY", "0", 1)
    setenv("DO_NOT_TRACK", "1", 1)
    guard let bundle,
      let weightsUrl = bundle.url(forResource: "care-label", withExtension: "cact"),
      let schemaUrl = bundle.url(forResource: "care-label-schema", withExtension: "json")
    else { throw CareLabelError.engine }
    let weights = try Data(contentsOf: weightsUrl, options: .alwaysMapped)
    let schema = try String(contentsOf: schemaUrl, encoding: .utf8)
    let loaded = weights.withUnsafeBytes { buffer in
      needle_load(buffer.bindMemory(to: UInt8.self).baseAddress, UInt64(buffer.count))
    }
    guard loaded >= 0, needle_init("", schema, nil) >= 0 else { throw CareLabelError.engine }
    started = true
  }

  private func run(text: String) throws -> LabelExtraction {
    var result = LabelExtraction()
    if text.isEmpty { return result }
    try start()
    needle_reset()
    let written = output.withUnsafeMutableBufferPointer { buffer in
      needle_complete(text, 512, buffer.baseAddress, Int32(buffer.count))
    }
    guard written >= 0 else { throw CareLabelError.engine }
    let envelope = output.withUnsafeBufferPointer { String(cString: $0.baseAddress!) }
    guard let object = try? JSONSerialization.jsonObject(with: Data(envelope.utf8)) as? [String: Any] else {
      throw CareLabelError.engine
    }
    let accepted = object["function_calls"] as? [[String: Any]] ?? []
    let withheld = object["suppressed_calls"] as? [[String: Any]] ?? []
    if let arguments = (accepted.first ?? withheld.first)?["arguments"] as? [String: Any],
      let data = try? JSONSerialization.data(withJSONObject: arguments)
    {
      result.json = String(data: data, encoding: .utf8)
      result.confidence = object["confidence"] as? Double
    }
    return result
  }
}

## Part 3: Care label (done, 1 October 2026)

What works:

- After Looks right in Check this piece she is asked "Add the care label?" with Add care label or Skip. A label can also be added, viewed, edited and removed later from the piece.
- The label photo is read on the phone with Apple Vision (English, Norwegian bokmål, German, French and Turkish). The photo is stored with the piece, shown only on the Care label screen, and deleted with the label, the piece or an unfinished import.
- A text reader picks out fibres with percentages, size and country of origin. The on-device extraction model then fills only fields the reader left empty, and only above its confidence threshold of 0.05. Every value must be printed on the label, so nothing is invented. Fields that cannot be read stay empty and editable.
- Fibre names in English, Norwegian, German, French, Swedish, Danish and Turkish are stored as one English name. Cotton, linen, wool, silk and modal set the piece's fabric with source label. A fabric she confirmed is never replaced, and removing the label clears only a fabric that came from it. Washing and care symbols are not stored.

Evidence: 15 fixture labels in `src/domain/fixtures/care-labels.json`. Domain tests C01 to C18 cover parsing, low confidence, invented values, fibre names, the fabric rules, storage and migration safety. The recorded extraction evaluation is in the [model README](../../modules/closet-vision/model/README.md): the model alone got 12 of 45 fields right and 12 wrong with no threshold and 2 right at 0.05; the text reader with the model at 0.05 got 40 of 45 right and 0 wrong. On the simulator the engine loads in about 160 ms, reads a label in about 0.4 s, and peaks at about 80 MB; Vision takes 1 to 2 seconds per label. Screens were checked with Maestro, including larger text. Screenshots are in [planning/build/care-label](../build/care-label).

Known limitations:

- Brands are only found by the extraction model, which is rarely confident enough, so brand is usually left for her to type.
- The text reader's fixture score is optimistic because its rules and the fixtures were written together. Her own labels are the real test.
- Urdu script is not supported by Vision text recognition.
- The engine is built for iOS 27 and linked into an iOS 26 app with a linker warning. It ran in the iOS 27 simulator only.
- The model adds 35.3 MB to the app.

Before the TestFlight build is signed off on her iPhone:

- Network check: turn on Settings, Privacy and Security, App Privacy Report, read three labels, and confirm Almari shows no network activity from label reading. Alternatively run the app from Xcode with the Network instrument and confirm no connections while a label is read.
