# Almari paths and acceptance stories

Audited against the route files and domain code on 11 October 2026. A story is a user outcome, not a screen label. Domain tests prove rules and persisted state; simulator flows prove navigation and controls; neither establishes generated-image fidelity. Simulator flows listed below already exist unless marked new. Their presence does not mean they passed on the current build. See [system analysis](system-analysis.md) for limitations and [validation](validation.md) for execution evidence.

## Scope still requiring runtime evidence

The story inventory covers every current non-layout route, including dynamic route variants. It does not assert exhaustive coverage of arbitrary user input or every OS interaction. Camera permissions, actual photo picking, native selfie/label models, share sheets, accessibility gestures and complete image fidelity require device/simulator or reviewed visual evidence. Current simulator seeds copy catalogue assets or recorded scan outputs; they do not establish recognition accuracy on new real head/outfit/hanging photographs.

Nine bundled selections and a separate local-download floor jacket now pass the actual local parser/selector, cutout bounds and Studio input preparation. The general loose-garment repair preserves the reviewed cord and excludes neighboring garments without photo-specific rules. The expanded mirror/rotation/size/tap gate still has 12 failures out of 56 variants. The [photo report](native-photos.md) records those limitations, previous cap/blazer/person repairs, source licences and remaining scene/fidelity gaps. The separately approved 20 live requests returned 17 images and three HTTP 502 failures. Visual review found eight clear failures and nine requiring owner review; the [live report](studio-photos.md) records provenance and does not certify reconstruction fidelity.

New `system/` simulator flows cover product-link input, date-first planning, custom-list editing and statistics; execution outcomes are recorded separately. One live Lindex product-page import now passes on the simulator, including saving its link/photo. Other retailer behavior, native share sheets and notification delivery still need broader runtime evidence beyond service mocks. Re-run existing flows against the current app before interpreting older QA reports as current defects.
