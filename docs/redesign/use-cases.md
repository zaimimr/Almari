# Almari use cases

Date: 2026-10-03. One row per use case. IDs follow the flows in `architecture.md`. Every inventory action in `docs/redesign/inventory/*.md` maps to a row below. States list which of empty, loading, error, offline, large text, bokmål the use case must cover, plus permission denied, generating, reduce motion where they apply. Maestro paths are planned; flows are written in Phase 3 and tagged with the use case ID.

Conventions used in Steps: "Sample closet" means the shared setup (clear state, skip onboarding, "Try the sample closet" on Today). "Seeded owned closet" means `seed-owned.sh`. Camera steps run on a simulator with fixture images unless marked real phone. Scan steps on the simulator use the fixture feed (`ALMARI_SCAN_FIXTURE`, see the Magic moments decisions in `architecture.md`). Rows marked real phone run their Maestro path on the owner's phone and are not part of the simulator gate; every magic moment also has a simulator row.
